## 🏠 About RoofPro

**RoofPro** is a modern roofing and waterproofing website designed to present services, showcase projects, and provide visitors with convenient ways to explore service details and estimate options.

The project combines a construction-focused visual identity with responsive layouts, reusable React components, and modern frontend development practices.

### 🎯 Project Goals

- Present roofing and waterproofing services professionally.
- Provide an attractive and responsive user interface.
- Showcase project images and service details.
- Make website navigation intuitive.
- Provide convenient contact and estimate interfaces.
- Maintain a modular and maintainable codebase.

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/GhousDeveloper/waterproofing-website.git
```

### 2. Open the Project

```bash
cd waterproofing-website
```

### 3. Install Dependencies

```bash
npm install
```

If the current project requires a peer-dependency workaround, use:

```bash
npm install --legacy-peer-deps
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Build for Production

```bash
npm run build
```

### 6. Preview the Production Build

```bash
npm run preview
```
